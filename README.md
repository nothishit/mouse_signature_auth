Аутентификация по росписи мышью (курсовая работа)
Требуется Python 3.8+ (tkinter входит в стандартную поставку для Windows). Сторонние пакеты не нужны.

  python mouse_signature_app.py      - запуск приложения (регистрация 5 росписей, затем вход)
  python -m unittest -v test_core    - автоматические тесты (11 шт.)
  python experiment.py 30            - модельный эксперимент (FAR/FRR/EER), ~1 мин

Профили сохраняются в profiles.json рядом с программой.
